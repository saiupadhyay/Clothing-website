BLACKFITS PRODUCT IMAGES REPOSITORY
======================================

You can place your high-resolution black T-shirt photos in this folder:
d:\BlackFits.com\clothing Website\public\images\

Example:
If you save an image here named:
  my-black-tee.jpg

You can reference it in the website or Admin Panel as:
  /images/my-black-tee.jpg

Alternatively, you can upload images directly from your computer inside the
Admin Panel using the "Upload from Computer" button!
